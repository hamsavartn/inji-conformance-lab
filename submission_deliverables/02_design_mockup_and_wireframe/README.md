# 02. Design Mockups & Wireframes

This directory contains the user interface mockups, wireframes, and design system documentation for the **MOSIP Inji Conformance Laboratory**.

## Deliverables Included

1. **`ui_main_dashboard.jpg`**: High-resolution screenshot of the main testing workbench showcasing:
   - 3-Way Actor Topology Configurator (Issuer, Wallet, Verifier)
   - Interactive Handshake Execution Control
   - Monaco Protocol Inspector (JWT/SD-JWT/CBOR syntax highlighting)
   - Dynamic Mermaid Sequence Diagram (14 real-time protocol hops)
   - Live WebSocket Telemetry Stream (inbound/outbound latency & status tracking)
   - Real-Time QR Code Byte Density & Scannability Meter

2. **`ui_interop_matrix.jpg`**: High-resolution screenshot of the Judge Conformance Matrix showcasing:
   - Automated 8-Lane Verification Matrix
   - Real-time pass/fail indicators across all 4 credential profiles
   - 100% Conformance Badge & execution timing telemetry

3. **`design.md`**: Comprehensive UI/UX specification detailing:
   - Dark-mode technical design system (MOSIP brand colors, high-contrast monospace accents)
   - Component hierarchy (Topology Selector, Monaco Inspector, Mermaid Graph, QR Meter)
   - State management model (Zustand reactive slices)
   - Micro-interaction and real-time animation guidelines
